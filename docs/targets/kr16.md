# Target Profile — KR16

This document describes the KR16 target for KRCompiler.
It is a work in progress; the authoritative data is in `plan.md`
§4 (Targets and data models), §10 (ABI), §9.6 (KR16 backend notes),
and Appendix C (Target profile summary).

## Status

- **Specified:** plan.md (see below).
- **Implemented:** KR16 backend complete — target descriptor, register
  definitions (R0-R4), 2-byte instruction encoding (R/I/L/S/B/J formats),
  instruction selection, assembler (KRO emission), linker support, and
  driver `-target kr16` support. End-to-end C compilation verified.
- **Frozen:** Not yet frozen. The KR16 ABI appendix
  (`docs/abi-kr16.md`) must be frozen before M7 (plan.md §10.2).

## Calling convention (KR16, from plan.md §10.2)

- Integer arguments in R0–R3; further arguments on the stack; return in R0.
- R4 is the frame pointer; SP is full-descending (by convention).
- Stack alignment is 2 bytes; aggregates are passed by value on the stack.
- `this` is passed as the first integer argument.
- Exact rules must be documented in `docs/abi-kr16.md` and tested with a
  calling-convention suite (plan.md §10.2).
