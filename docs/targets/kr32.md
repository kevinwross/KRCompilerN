# Target Profile — KR32

This document describes the KR32 target for KRCompiler.
It is a work in progress; the authoritative data is in `plan.md`
§4 (Targets and data models), §10 (ABI), §9.5 (KR32 backend notes),
and Appendix C (Target profile summary).

## Status

- **Specified:** plan.md (see below).
- **Implemented:** Not yet. No KR32 target descriptor exists in `src/backend/targets/kr32/`.
- **Frozen:** Not yet frozen. Target descriptor changes require an ADR under
  `docs/decisions/` (plan.md §18.1).

## Calling convention (KR32, from plan.md §10.2)

- Integer arguments in R0–R3; floating-point arguments in F0–F7; further
  arguments on the stack.
- Integer return in R0 (R0/R1 for 64-bit), FP return in F0/F1.
- R7 is the frame pointer; R11 is the thread pointer.
- Public call boundaries are 16-byte aligned.
- Aggregates larger than 8 bytes use a hidden `sret` pointer.
- Tile registers are caller-saved; matrix values cross calls by pointer.
