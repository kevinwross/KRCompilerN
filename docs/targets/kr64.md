# Target Profile — KR64 (Placeholder)

This document describes the KR64 target for KRCompiler.
KR64 is a placeholder target and is **not** part of v1.0.

## Status

- **Specified:** plan.md §4.4 (64-bit target), §4.5 (Out-of-scope target families).
- **Implemented:** Not yet. No KR64 target descriptor exists.
- **Frozen:** Not yet frozen. The compiler MUST NOT ship a 64-bit backend
  before the 64-bit VM specification and its ISA are approved (plan.md §4.4).

## Constraints

- The 64-bit VM specification is a separate deliverable (plan.md §4.4).
- The IR, ABI, and backend interfaces must not assume 32-bit pointers,
  `long`, or addresses (plan.md §4.4).
- A target descriptor slot `kr64` is reserved (name placeholder).
